## About
Define what an NLP Pipeline is, how to use the Hugging Face Pipeline API, and explain the framework for selecting a pre-trained model.  Also construct pipeline for sentiment analysis.


## Learning Objectives

*You will be able to:*

- Define an NLP pipeline and Hugging Face Pipeline API.
- Explain the framework for selecting a pre-trained model.
- Construct a pipeline for sentiment analysis using encoder models and compare performance across models.

- Write and run Python code in a Jupyter notebook.
- Create basic Python functions.
- Import and use `pandas` and `numpy`.
- Understand, run, and evaluate classification models and metrics in `scikit-learn`.
